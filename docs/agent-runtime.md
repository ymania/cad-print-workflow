# 受控二维 CAD Agent

当前入口：`frontend/studio.html`。这是有本地工具执行与反馈循环的二维Agent；不是通用CAD内核，也没有通过全面识图验收。已有DeepSeek真实调用结果，见[实测记录](agent-live-validation.md)。

## 使用顺序

1. 选择主图，选四角校正；已经方正或为局部图时明确选择保留当前图像。
2. 输入一条已知实际尺寸并点选两端进行标定。输出比例不是输入标定比例。此处仍需人工确认，不自动猜毫米。
3. 可多选追加细节/尺寸参考图。其他视图仅提供证据，不能套用主图像素比例。
4. 点选服务卡片，填写对应Key和绘图要求，核对接收地址并授权本次最多3轮调用。DeepSeek默认使用省时思考强度，高级配置可改为深入；其他服务不发送这个专用参数。
5. 本地Worker先计算边缘、直线和圆候选；模型收到校正主图、参考图、标定、候选证据和用户要求，返回结构化几何与关系。
6. 本地Worker求解约束并对照图像检查轮廓。发现不满足关系或明显偏差时，反馈给模型修正；最多初始识别加两次修正，重复方案提前停止。
7. 存在关键问题时暂停。点击卡片定位到图上，也可点击蓝色锚点选择卡片，输入回答后显式继续。尺寸修改使用“应用并锁定”，本地重算，不需要额外API调用。
8. 逐项锁定已核对的尺寸和关系。如果尚有未完全约束的坐标，须人工核对叠图并明确确认近似定位；存在约束错误或未回答问题则不能导出最终图。
9. 在第4步确认，导出DXF/PDF/FreeCAD宏/参数；用“保存项目”下载校正图、草稿、约束、锁定状态、补充参考图与回答。恢复后重新求解和审核。Key不进入项目文件。

“演示Agent流程（无Key）”使用固定模拟模型响应，但经过真实本地图像分析、约束求解和导出流程。演示的80毫米圆不是实际识图结果，不能用演示成功证明某服务的模型质量。

## 模块与执行规则

- `agent-image.js`：有界边缘采样、直线投票、确定性圆候选采样；按轮廓采样点对比原图的5像素邻域。检测会受文字、辅助线、噪点影响，不是可靠性概率。
- `agent-geometry.js`：结构验证、局部数值投影求解、约束残差、自由度估计、相切点是否落在线段/圆弧、用户锁定保护、导出适配。
- `agent-worker.js`：将图像与几何计算放到后台，限制单任务60秒，支持取消。最多80图元、160约束；闭合路径生成的连接约束也占额度。
- `agent-runtime.js`：直接兼容API调用及确定的修正循环。只接收数据，不执行模型代码。不携带Cookie、不跟随重定向，错误提示不输出Key或原始响应体。流式接收会区分等待、思考字符计数和方案生成，不展示或保存模型思考内容。每轮首响应120秒、接收空闲90秒、总计300秒上限；用户可停止，已发送调用仍可能计费。流式网络包装上限32MiB，非流式4MiB，最终方案另限2M字符；流式终止标记缺失或长度截断会阻断。无自动网络失败重试。
- `studio-agent-ui.js`：中文进度、模型卡片、问题与尺寸锚点、确认与撤销、项目恢复。确认值由程序在后续模型响应中强制保留；模型改变锁定图元类型或闭合路径时拒绝结果。

支持的图元：直线、圆、圆弧；多边形和星形可拆为线段。

支持的关系：长度、半径、直径、水平、垂直、平行、垂直相交方向、夹角、点重合、点距、同心、线圆相切、圆圆内/外切。模型声明的闭合路径由程序补齐首尾连接约束。路径项可为图元ID，或 `{id,reverse:true}` 反向经过该段；圆弧的CAD逆时针定义不变。不支持的几何必须作为问题返回，不能静默丢掉。

求解器是有限迭代的局部方法，依赖合理初值。约束通过阈值为0.001毫米或0.001度，不代表照片精度。自由度是数值Jacobian秩估计，不是形式证明；收敛不证明唯一解。约束不足时保留近似位置并明确人工审核；冲突时不宣称无解的数学证明，仅报告当前求解未满足。

图像匹配作为软证据：修改尺寸后可能偏离照片手绘线，这不意味着确认尺寸错误。模型修正不能靠删掉已存在约束通过检查。最终导出仍需人工检查缺失构件、误读尺寸与纸面比例。

## 当前边界

已接通的完整循环仅覆盖上述二维图元与关系。手动四角定位仍是必经人工入口之一，尚未接入自动纸边OpenCV检测、纸面去弯曲、多视图自动配准、通用曲线、三维建模、自动无碰撞标注布局和原生DIMENSION。FreeCAD宏仍是几何草图，不把网页约束转成FreeCAD驱动约束。

当前以一张已标定主图为坐标基准，其他图片为补充证据；不是多个独立尺度构件的自动排版器。DXF/PDF整体纸面比例在导出时设置，FreeCAD保留实际毫米。旧的直接识图首页仍保留，用途和本工作台不同。

## 验证

运行 `node --test tests/browser/*.test.cjs` 与 `pytest -q`。

包含矛盾尺寸阻断、相切有限段范围、锁定尺寸与闭合路径防改写、闭合端点求解、修正上限、问题暂停、重复方案停止、取消、请求隐私、多图请求、图像候选及轮廓偏移检查。浏览器合成演示已跑通，实际下载参数的直径从80修改为60后，半径在数值容差内为30。

2026-11-14经用户授权使用临时Key进行了4次真实DeepSeek调用。80毫米圆识别成功；吊钩最终只得到部分草稿和4个问题，未通过完整轮廓验收。没有把Key、原始私人照片或私人测试项目提交到仓库。本轮浏览器控制工具持续超时，API与几何实测不能代替网页端的真实调用验收。详见[实测记录](agent-live-validation.md)。
