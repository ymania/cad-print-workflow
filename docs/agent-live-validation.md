# DeepSeek 实测记录（2026-11-14）

模型：官方API `deepseek-flash`。用户授权使用临时Key，共发送4次图片请求；Key不进入代码、日志、项目或提交。下列耗时是这次观察值，不是性能承诺。

| 案例 | 模式 | 耗时 | 结果 |
| --- | --- | ---: | --- |
| 带直径文字的合成圆 | 原非流式 | 4.326秒 | 读出80毫米，圆半径40，几何约束通过，无需修正 |
| 用户吊钩参考照片 | 原非流式 | 120.483秒 | 接收空闲超时，未得到完整方案 |
| 同一吊钩 | 流式，原4MiB网络上限 | 90.317秒 | 思考进度正常，但被网络响应上限截断 |
| 同一吊钩 | 流式，32MiB包装上限，low思考 | 88.171秒 | 返回8个图元、4个问题；暂停，不导出最终图 |

吊钩不是成功案例。模型只输出阶梯轴上半部、中心线和一个整圆，遗漏主要钩形圆弧。轮廓图像支持度约46.5%，不是识图准确率。已列约束通过不等于完整零件通过；问题暂停和导出阻断发挥了作用。毫米标定来自参考图轴段的人工近似，只用于初值，不是该照片准确标定的证明。

## 本次修正

- 接入Chat Completions SSE，区分等待、思考字符计数、几何方案生成；不显示或保存思考正文。
- UTF-8跨块解码、分段JSON组装、保活注释过滤；截断或未收到完成标记时阻断。
- 流式包装上限32MiB，最终方案另限2M字符；非流式保留4MiB上限。接收空闲90秒，单轮总计5分钟，仍可取消。
- 官方DeepSeek Flash默认发送 `reasoning_effort: low`；高级设置可选high，不向其他服务发送此专用参数。
- 闭合路径支持反向遍历线段/圆弧，不改变DXF逆时针圆弧定义。合成半圆回归测试验证连接方向。
- 存在问题时，界面明确提示草稿未完成。识图规则补充轴宽约束、开口圆弧与整圆区分、避免索要可推导的圆心坐标。这些提示补充尚未另做付费复测，不宣称已解决吊钩漏画。

## 验证范围与后续

39项JS测试和12项Python测试通过。之前的浏览器合成流程已验证图上锁定、保存恢复与导出；本轮浏览器控制工具持续超时，因此本次真实调用是在本地加载同一套前端Agent模块完成，不能声称已验证线上网页到服务商的完整调用链。

下一项需要解决的是构件完整性与复杂相切图的结构化建模：将已确认的标准构件解析构造加入工具库，识图环节负责选择构件与提取尺寸，再用确定的程序构造和检查。不能靠放松残差阈值、删除相切条件或隐藏问题使测试“通过”。

官方接口依据：[视觉输入](https://api-docs.deepseek.com/guides/vision/)、[思考强度](https://api-docs.deepseek.com/guides/thinking_mode/)。
