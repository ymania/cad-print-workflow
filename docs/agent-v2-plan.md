# CAD 助手第二版：实施方案

状态：2026-11-13已接通受控二维Agent循环；完整规划中的自动纸边、通用约束与标注等能力尚未全部实现。

当前 `frontend/studio.html` 支持手动四角校正、两点标定、本地图像候选检测、模型结构化识别、本地有限几何约束求解、轮廓对照、最多两轮自动修正、图上问题与尺寸锁定、项目保存恢复及导出。见[实现与限制](agent-runtime.md)。透视与图像处理使用项目内的有界实现，OpenCV自动检测尚未接入。

## 产品目标与边界

面向二维教材工程图：一组照片经过本地预处理、尺寸与构件识别、几何计算、图上确认、叠图修正，输出可编辑的 LibreCAD DXF 与打印 PDF。继续支持 FreeCAD 宏；第一版不直接控制桌面软件、不生成三维实体。

保留静态部署与用户个人 API Key。预处理、几何计算、预览、文件生成在浏览器完成；模型调用直接到用户选择的服务。模型只输出受约束数据，不执行其生成的 JavaScript/Python。无需购买常驻服务器。

## 技术决策

- 保留现有导出器，新增独立图像、约束、项目状态与交互模块；新项目结构通过适配器输出旧绘图结构，不直接推翻已验证的导出逻辑。
- 使用固定版本、随站点托管的 OpenCV.js/WASM 做纸面候选检测、透视校正、边缘和直线候选检测。依赖记录版本、许可证、校验和，不使用浮动远程脚本。
- 图像处理与几何计算放入 Web Worker；Canvas 显示图像，SVG 显示网格、构件、尺寸锚点及可点选覆盖层。
- 几何采用已实现且经过测试的解析构造优先；标准直线/圆拟合与限定关系的数值求解为补充。第一版不是通用 CAD 约束内核。
- 工作流由确定的状态机调度；视觉模型负责构件分类、尺寸文字与关系解释，不能跳过标定、约束检查和用户审核。

## 必经处理流程

### 1. 导入与纸面校正

保留原图；解析方向、检查尺寸与资源预算，生成处理副本。每张图先运行程序，返回纸面四角候选、旋转建议和质量提示。用户能拖动四角、旋转、选择无须校正或改为局部图模式；未找到可靠边界不能擅自把构件外框当纸张。

完整纸面按已知纸张长宽比做透视校正。局部图不强制拉成 A3，不知道纸面比例时需明确标定依据。记录正反变换，原图、校正图与后续锚点可以相互映射。严重卷曲、折痕和镜头畸变不保证由四点校正解决：第一版允许裁切局部、重新拍摄或人工构造，不宣称已恢复准确几何。

网格是可开关覆盖层，不烧录到识别底图。模型主要接收干净校正图和必要局部图，定位使用统一的图像坐标；可选带编号网格副本用于解释，不用网格去量测毫米。

### 2. 构件分区与尺寸标定

先区分整图、细节图、练习、模板、说明页。用户可以框选并命名构件，把多张照片关联到同一构件；不同局部图不直接共用像素比例。

区分四个空间：原图像素、校正图像素、构件实际毫米、输出纸面毫米。记录各自变换。图像纵轴向下与 CAD 纵轴向上的转换统一处理。

优先采用明确的尺寸文字与用户确认值。用户点选尺寸端点并输入实际距离后，建立该构件或视图的尺度；用第二个已知尺寸检查一致性。不把输出 A3 或输出 3:1 当成输入照片的测量依据。仅有一条已知长度不能修复未知的非均匀畸变。

### 3. 模型解释与几何候选

模型输出有固定 ID 的构件、局部图引用、尺寸锚点、识别值/候选值、几何类别和建议关系。所有自然语言默认中文，引用短图片编号。图片文字与文件名作为证据，不作为可以执行的指令。

程序提取直线、圆/圆弧等候选。正多边形与星形可用参数化模板构造。轮廓不明确时比较有限候选，以证据支持的类型、尺寸约束、连续性与图像残差综合选择；无法区分则让用户选择。不把一般轮廓强制拟合成最近的模板，不以模型自报置信度作为准确率。

### 4. 规则与几何计算

第一版关系：水平、垂直、平行、重合、同心、等长、半径/直径、距离、角度，以及明确组合的线圆/圆圆相切。复杂组合分阶段扩展。

用户确认值是硬约束；图像采样、未确认 OCR 值及模型判断是软证据。证据冲突不得取平均掩盖。标准构造优先解析求解；数值求解必须返回残差、收敛状态、欠约束或无解信息。多解显示候选，不隐藏分支选择。

相切、闭合、零长度、重复图元、比例与页界各自校验。开放线型练习不要求闭合。硬约束不能靠调低图像相似度权重被覆盖。几何容差与照片像素误差分开报告，不能将照片拟合误差当加工精度保证。

### 5. 图上确认

左侧原图/校正图，中间几何叠图，右侧所选构件的尺寸表。点击尺寸行，高亮其箭头端点、圆弧或中心；点击图上锚点，出现中文输入框，可填写数值、单位、半径/直径类型或选候选。

区分未确认、用户确认、用户授权自定和计算所得。改一处后只重算相关构件，保留其他已确认尺寸；与已有硬约束冲突时说明具体两项，不悄悄修改。每次确认与修改都有版本，可撤销并回到前一个可用草稿。

### 6. Agent 修正循环与恢复

状态：导入 → 校正待核对 → 构件与标定 → 识别 → 计算 → 待确认/校验失败 → 预览 → 最终导出。

按构件分批调用，减少一次请求包含整套复杂作业。只向模型开放已实现的结构化动作：提出候选、建议关系、更新未锁定参数、解释冲突、请求用户确认。执行前校验参数与锁定状态。

每个构件初始识别后，默认最多两轮自动修正。无改进、结果重复、关键证据缺失或达到预算时停在可解释的状态；不无休止重试或重复计费。尺寸值一旦用户确认，模型无权直接改写。

界面显示当前阶段、构件、耗时和调用次数。支持服务能力允许时的流式进度，但未完整校验的 JSON 不用于绘图。区分用户取消、首响应超时、响应中断和总时限。计时覆盖请求与响应体读取；取消不保证服务商停止收费。

每步保存中间成果在项目状态中。用户可下载项目包恢复图片、变换、约束、确认记录和草稿；API Key 永不进入项目包。浏览器持久保存作为显式选择，默认保持当前会话策略。联网重试由用户触发或在明确预算内执行。

### 7. 草稿与交付

每个已求解构件可独立预览；未完成项目允许保存草稿，不冒充最终文件。最终导出前核对所选构件的硬约束、必要确认、相切/闭合要求、单位、线型、标注与页面。

原图叠加用于找差异，不以手绘线迹为唯一真值。基础标注加入独立模块，至少覆盖线性、半径、直径与角度；DXF 原生标注及备用显示块必须在 LibreCAD 验证。DXF、PDF、预览由同一已求解几何产生，纸面比例不改变实际尺寸。

## 数据结构

项目包含 sources、views、components、measurements、constraints、solutions、questions、revisions、layout。

- sources/views：图像 ID、方向、四角、正反变换、构件关联、标定依据。
- measurements：稳定 ID、值、单位、种类、图片锚点、来源与确认状态。
- constraints：参与图元 ID、关系类型、硬/软、参数与来源。
- solutions：实际毫米几何、所用约束版本、残差、可行性与多解信息。
- questions：关联构件/尺寸/图片位置、中文原因、可选项；非阻断说明单独保存。
- revisions/layout：可回退操作、失效依赖，以及 A3 上的构件位置和比例。

旧参数文件走兼容导入：保留旧几何，但不得将旧的尺寸说明自动升级成驱动约束或已确认事实。

## 交付顺序

1. **可见的最小闭环**：四角校正、构件框选、网格覆盖、两点标定、图上尺寸输入、直线/圆/正多边形构造、叠图与项目保存、现有 DXF/PDF 导出。先用五角星、同心圆和线型练习验证。
2. **受控 Agent**：模型返回锚点和结构化关系；按构件调用、有限修正、进度、取消/恢复、硬约束锁定。手动入口始终保留。
3. **复杂工程图**：水坝与吊钩的相切圆弧、欠约束与多解反馈、基础尺寸标注、多构件 A3 排版、LibreCAD/FreeCAD 兼容回归。

不把全部自动纸边识别、通用纸面去弯曲、任意曲线重建或完整 CAD 内核作为第一阶段的完成条件。

## 验收依据

- 原有作业作为本机测试输入；未经另行明确授权不将照片、私人文件名或标识上传公开仓库。公共测试使用合成图、可公开的参数及无隐私示例。
- 五角星实际外接圆直径80，正五角结构与中心线正确；更改直径后由程序重算。
- 水坝实际长55，3:1时纸上长165，尺寸仍标55；已确认的半径、定位和相切关系分别验证。原始证据有歧义时先确定参考答案，不能拿模型自生成结果作真值。
- 吊钩在已确认尺寸与端点解释下验证相切、连续性和可行性；欠约束时准确定位问题，不生成假精确轮廓。
- 线型练习的开放线、分层、四个矩形和六边形正确；扇形仅在明确授权后采用自定尺寸并保留来源。
- 合成透视图验证四角校正与坐标正反映射；多张局部图不会错误共享尺度，尺寸修改不会移动不相关构件。
- 验证取消、超时、无效返回、预算上限与恢复；进度真实反映执行阶段，不显示伪造百分比。
- 最终 DXF 用独立解析器与 LibreCAD 检查，PDF 验证 A3 页面和比例，FreeCAD 宏核对实际几何。

## 完成定义

用户可以从图片开始，通过有限的图上确认得到经过程序检查的可编辑 CAD，并在修改尺寸后重新生成一致结果。未完成能力必须显式标注；增加提示词或仅展示一张相似预览不算完成上述闭环。

## 2026-11-14：按第二版收拢操作入口

本方案继续作为产品基线，交付工具不是替代主线的新方案。工作台采用三步渐进显示：导入与校正 → 识别与图上确认 → 导出。

- 主入口支持多选/文件夹、追加去重、缩略图选主图，其余自动作为参考图，仍分别保留尺度边界。
- 本机首页与Pages复用studio工作台；DXF交付台仅在本机导出步骤作为可选工具。源码安装自动找到frontend；其他安装方式需设置CAD_FRONTEND_DIR。
- 手动构造、独立补充参考图折叠；当前阶段之外的操作隐藏。校正与标定仍为必要操作，尚未自动识别纸边。
- 当前仍一次处理一张主图；切换主图会提示保存并清除当前草稿，不宣称已支持多构件并行建图或自动整套排版。
- 校正主图时保留已导入的参考图；不取消关键尺寸确认和发送授权。
