# 外部模块与自己的构造工具

2026-11-14。当前决定：自己维护识图、尺寸确认和输出规则，第三方工具通过数据接口接入，不运行模型生成的任意代码。

- [CAD-MCP](https://github.com/daobataotie/CAD-MCP)：MIT，桌面COM控制层，提供绘图、查询与修改工具。借鉴“绘制→检查→修正”的分工；它不是当前静态网页的图像识别或几何内核。
- [Maker.js交点实现](https://github.com/microsoft/maker.js/blob/master/packages/maker.js/src/core/intersect.ts)：可作为二维交点运算适配器的候选。实际引入前应固定版本、保留许可证及打包依赖声明，并验证浏览器包的依赖。当前尚未将其代码复制进项目。

## 已完成的独立构造

`frontend/standard-hook.js` 暴露 `CADStandardHook.construct(params)`（Node中可require）。输入13个真实毫米尺寸，输出现有Agent几何结构；7段直线、7段圆弧、8处相切，以及有方向的闭合路径。模型无需提供所有圆心和切点。

只适用于竖直轴、轴肩对称、主圆心横向偏置、钩尖位于指定交点分支的教材吊钩。缺尺寸或无有效交点时拒绝构造，不自动改尺寸。不支持任意吊钩或旋转配准。

测试覆盖完整闭合、有限圆弧上的切点、修改半径后重建、缺尺寸与不可能尺寸。已通过hook-adapter接入网页参数编辑、模型结构化工具入口与图片位置确认。模型可返回hook参数和逐项来源，程序生成轮廓；所有参数须核对后才能导出。尚未使用真实模型验收此新入口，不能宣称照片识图已通过。

接入顺序：先让模型选择受支持构件并返回有来源的尺寸；用户核对类型和关键尺寸；程序解析构造；对照图片定位；沿用现有导出门禁。通用图元流程继续保留。将来第三方几何适配器只负责交点/裁剪，不能覆盖用户确认值。

## 网页入口

完成校正、标定后，在右侧展开“标准吊钩参数工具”。填写13项实际毫米尺寸和内圆中心像素位置，点击重建，再核对并确认全部构造尺寸与关系。修改后必须重新构造；已确认的吊钩不能由模型替换，仍可在本地参数区修改。当前只支持单个竖直教材吊钩；没有自动旋转或镜像配准。参数随项目保存，恢复时程序重新构造并检查。
